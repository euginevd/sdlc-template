# Lessons

Mistakes an agent has made, each with its one-line fix, by area ([AGENTS.md](../AGENTS.md) rules 1 and 18). Read Repo and Docs every session, and an area's section before working in it. Numbered so reviews can cite them (lessons 9); a line goes once a check catches the mistake.

## Repo

1. Shell scripts must keep LF line endings or bash fails on Windows; don't override `.gitattributes`.
2. A `CLAUDE.md` in the repo makes Claude Code skip `AGENTS.md`. Don't add one.
3. A page that pins its CSS or JavaScript by integrity hash goes unstyled or dead after an edit: recompute each `sha384` after the last edit and load the page in a browser.
4. Run the web apps' tests from an upper-case `C:\` path (`Set-Location C:\<repo>\apps\<app>`): from `c:` Vitest loads twice and every jest-dom matcher fails as "Invalid Chai property".
5. Never rewrite a source file with Windows PowerShell `Get-Content`/`Set-Content`: it reads UTF-8 as ANSI and writes a BOM (`·` became `Â·`). Use the Edit tool, or Python with `encoding="utf-8"`.
6. A script pasted into CloudShell runs interactively, where `!word` is history expansion (`!starts_with` dropped a check): write ``== `false` `` instead.
29. Git Bash's `/c/…` spells the drive `C:` while the project is `c:`: Vitest fails with "failed to find the runner" and Compose asks for `--allow=fs.read`. Run both from `cd "c:/…"`.
30. Docker Compose 5 builds through bake, which on Windows refuses with *additional privileges requested: fs.read*: build with `BUILDX_BAKE_ENTITLEMENTS_FS=0 docker compose ... up -d --build`.

## CI

7. A boolean `workflow_dispatch` input is empty on a push, which GitHub counts as `false`: test the event, as in `github.event_name != 'workflow_dispatch' || inputs.deploy`.
8. The AWS CLI on GitHub's runners reads `--cli-input-json file:///dev/stdin` as empty: pass a request through a private temporary file, and delete it after.
31. `.lefthook/pre-push-scan.sh` reads the pushed refs from stdin, so run by hand in the background it waits forever: let `git push` run it through the hook.
32. ESLint and `tsc` passing isn't the web lint: `npm run lint` also runs `prettier --check`. Run it in each changed app before pushing.
33. CI's pyright checks `tests` as well as `src`: run `uv run pyright` with no path, as CI does.
34. A cloud agent container can be refused by an outside API (Binance: HTTP 451, restricted location): test against recorded replies, and the owner makes the first live run.

## Docs

20. The GitHub MCP tools add a "Generated by Claude Code" footer to PR bodies and comments, which rule 15 forbids: check the posted text and edit the footer out.
45. `wc -w` counts symbols such as `·` as words in a UTF-8 locale but not in C, so a doc passed locally and failed CI's length check: count with `LC_ALL=C.UTF-8`, as CI does.

## Web apps

21. CSS `@keyframes` names are global: a new stylesheet's `rise` replaced another's and hid a sign-in form. Prefix a new stylesheet's keyframes (`chat-rise`).
22. `display: none` on a button's only text removes its name: hide a label visually (clipped, 1px) instead.
23. A `file:` dependency's path in `package-lock.json` is relative to the app's folder (`../../packages/<pkg>`): build in the image at the repo's depth (`/web/apps/<app>`), or `npm ci` can't find it and prints only its usage.
24. npm 10 drops the `libc` fields that npm 11 writes, so CI's `npm ci` on Node 24 sees a changed lock: write lock files with the npm CI uses (`npx npm@11 install`).
25. axe flags low contrast on text caught mid fade-in: run accessibility checks with `reducedMotion: "reduce"` so they see the settled page.
35. A web font linked from Google Fonts breaks the content security policy: install it from npm (`@fontsource/<font>`) and import it in the app's entry file.
36. Headless Chrome on Windows lays a page out at 500px at least and crops a narrower screenshot: check phone layouts at `--window-size=500,…`.
37. A page sized for one laptop left a third of a bigger window empty: screenshot a changed page at the developer's window size and at 1440×900.
38. Replacing a CSS block by slicing from its comment to the end of the file drops every rule after it: slice to the next block's comment, then check the rest survived.

## Python and Postgres

26. Two services that create the same tables at start (LangGraph's checkpointer and store) race on Postgres's catalog and one fails with `UniqueViolation` on `pg_type`: retry the setup a few times on `UniqueViolation`, `DuplicateTable` and `DuplicateObject`.
27. Semgrep blocks `urllib` and `http.client` calls to a URL from a variable, even when the scheme is checked: use `httpx`.
39. Semgrep blocks SQL built with an f-string, even from fixed names: write each query whole.
40. psycopg reports a rowcount of -1 for `INSERT ... ON CONFLICT DO NOTHING`, so a rowcount check passes a duplicate: read `RETURNING` instead.
41. Opening a log file per line lost about 2% of lines when threads wrote at once on Windows, even under a lock: keep one handle per file, shared under the lock.

## Reliability

42. A timed-out call isn't proof it failed (a live order was nearly sent twice): keep the record pending, look it up by its client id, and only then retry.
43. A second reader of a rate-limited source doubled the calls and tripped a 429, and a failed read showed as empty: cache the last good reading and fall back to it.
44. A new check first missed one route that triggers the same action: list every route to the action before adding a check.
