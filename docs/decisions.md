# Decisions

The project's architecture decision record (ADR) log: the decisions in force, one line each, newest last, as **the decision** (date): why, and what it replaced or ruled out. A superseded decision keeps its number as a one-line pointer (*Superseded by N:* what it was), so citations still work; git keeps the full text.
